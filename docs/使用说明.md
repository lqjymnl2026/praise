## 二、📱 手机采集端（/mobile）—— 只负责“收”

打开手机浏览器访问采集端地址，建议「分享 → 添加到主屏幕」变成 App 图标。

### 1. 📷 拍照识别
1. 点「拍照识别」→ 允许相机权限
2. 对准老赞美诗书页拍照（光线充足、页面平整、单首歌一页最佳）
3. 系统自动识别 → **歌名 / 首句 / 歌词**自动填入表单
4. 核对修正 → 点「保存并继续」→ 自动分类入库

### 2. 🖼️ 相册照片
1. 点「相册照片」→ 从手机相册选照片（**可多选**）
2. 系统批量导入并自动识别（自动转正、缩放，识别失败自动进“待确认”）
3. 显示结果：✅识别成功 / ⚠️待确认 / 🔄重复 / ❌不完整

### 3. 📄 文件导入
点「文件导入」→ 选 PDF / Excel / Word 文件（可多选）→ 自动切分曲目、识别歌名歌词。

### 4. ✍️ 手动录入
歌名（必填）、首句、歌词、作者/作曲、来源、备注 → 保存并继续（自动清空，连续录入）。

> 保存后顶部显示：`已保存《歌名》✅ · 分类：教会生活·圣餐`，可即时确认分类是否正确。

## 三、🖥️ 后台管理端（/）—— 负责“管”

### 1. 工作台
- 统计卡：总曲目 / 待审核 / 疑似重复组 / 已入选 / 资料不完整 / 已淘汰 / 平均评分
- **圣诗分类分布**（大类）+ 细类分布（本套特有）
- 编选进度（候选→初选→终选→最终出版）
- 最近导入结果、快捷入口

### 2. 曲目收集
- **批量导入**：拖拽 Excel/CSV/PDF/Word/图片/音频；Excel 列名自动匹配（歌名/歌曲名称/title…）
- **导入模板下载** + 示例文件
- **手工新增**：完整表单（含大类/细类随内容自动识别）
- **📱 快捷收集页**按钮 → 跳到手机采集端
- **📷 拍照识别填表**：桌面也能拍照/选图识别后填表

### 3. 智能整理
- **一键智能整理**：对全部（或仅待审核）重新分类 + 去重
- OCR 引擎状态：Vision / tesseract.js（内置离线中文，已就绪）
- **疑似重复**：分组展示匹配度 → [合并到这首] / [保留两条] / [不是重复]
- **待确认资料**列表：一键跳到编辑

### 4. 曲目库
- 搜索（歌名/首句/作者/作曲/曲调）
- 筛选：**大类 / 细类**（本套特有）、主题、场景、类型、状态、评分、待确认、疑似重复
- 排序、分页；批量操作：加入候选库 / 初选 / 终选 / 最终出版 / 淘汰 / 删除 / 导出选中
- 编辑弹窗：所有字段 + **手动修改大类/细类** + 附件上传（曲谱/音频/图片）

### 5. 筛选审核
- 状态页签：待审核 / 候选 / 初选 / 终选 / 最终出版 / 淘汰
- 每首歌：**点星评分（1-5）**、评审意见、一键晋级 / 淘汰 / 已确认 / 需修改

### 6. 导出中心
- 范围：全部 / 编选报告 / 待审核 / 选中 / 按大类 / 按细类 / 按状态 / 自定义筛选
- 格式：Excel / Word / PDF / CSV
- **导出表含「大类 / 细类」列**
- **编选报告**：一键生成《编选总表》四种格式
- 已生成文件列表可下载

## 六、常见问题

| 问题 | 解决 |
|---|---|
| 拍照/相册识别不出 | 光线充足、页面平整、单首一页；安装 tesseract 或配置 AI 接口可提升 |
| 识别个别字不准 | fast 模型限制；可在后台编辑修正；配 AI 视觉接口最准 |
| 公网打不开 | 隧道进程可能已停，找管理员重启并更新地址 |
| 手机相册按钮不弹 | 用 Safari/Chrome 打开，勿用微信内置浏览器 |
| 想固定域名 | 配 Cloudflare 账号 + 命名隧道（可协助） |
| 开机自启 | 已装 LaunchAgent，重启电脑自动运行（或终端执行 launchctl bootstrap） |
